1. Teoría del Laboratorio

Etiquetas semánticas de HTML5

Las etiquetas semánticas permiten organizar el contenido de una página web de una manera más clara, ordenada y significativa. En vez de meter todo dentro de bloques genéricos, cada etiqueta indica qué función cumple esa parte de la página.

¿Por qué usar etiquetas semánticas?

Podemos identificar cada área de la página usando etiquetas como <header> para el encabezado, <nav> para la navegación, <main> para el contenido principal y <footer> para el pie de página. Esto facilita que los desarrolladores, navegadores y herramientas de accesibilidad comprendan mejor la estructura de la página.

Las 7 etiquetas nuevas
EtiquetaFunción
<header></header>Define el encabezado de una página o sección.
<nav></nav>Contiene los enlaces principales de navegación.
<main></main>Contiene el contenido principal de la página.
<section></section>Agrupa contenido relacionado.
<article></article>Contiene contenido independiente.
<aside></aside>Contiene información complementaria.
<footer></footer>Define el pie de página o de una sección.
¿Qué podemos colocar dentro de cada una?
Etiqueta¿Qué podemos colocar allí?
<header>Nombre del sitio, logotipo, título principal o una breve presentación.
<nav>Enlaces o menú para acceder a Inicio, Nosotros, Servicios, Contacto, etc.
<main>El contenido principal: información sobre un proyecto, producto o tema.
<section>Un grupo de contenido relacionado, por ejemplo "Sobre nosotros" o "Nuestros servicios".
<article>Una noticia, publicación, artículo, entrada de blog o información independiente.
<aside>Un dato curioso, recomendación, información adicional o contenido relacionado.
<footer>Nombre del autor, información de contacto, derechos de autor, año o enlaces.
El idioma del documento: lang="es"

lang="es" es un atributo de <html> que indica que el idioma principal de la página es español. Se escribe dentro de la misma etiqueta de apertura: <html lang="es">. La etiqueta de cierre sigue siendo </html>, sin el atributo.

Ejemplo completo
<header> <h1>Mi sitio web de tecnología</h1> <p>Información sobre innovación y tecnología.</p> </header> <nav> <a href="#">Inicio</a> <a href="#">Tecnología</a> <a href="#">Proyectos</a> <a href="#">Contacto</a> </nav> <main> <section> <h2>Innovación tecnológica</h2> <p>La innovación permite crear nuevas soluciones para diferentes necesidades.</p> </section> <article> <h3>La inteligencia artificial</h3> <p>Es una tecnología utilizada en diferentes áreas de la sociedad.</p> </article> <aside> <h3>Dato curioso</h3> <p>La tecnología forma parte de muchas actividades que realizamos a diario.</p> </aside> </main> <footer> <p>Elaborado por: Mario Carrasco</p> <p>11° A - 2026</p> </footer>
