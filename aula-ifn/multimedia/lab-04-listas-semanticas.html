1. Teoría del Laboratorio

Listas semánticas: <ul>, <ol> y <li>

Las listas nos permiten organizar información que tiene varios elementos relacionados: una serie de pasos, un top de artistas, un menú de navegación, ingredientes de una receta, etc. En HTML existen dos tipos de listas, y ambas se construyen con elementos <li> (de "list item", elemento de lista) en su interior.

Lista ordenada — <ol>

<ol></ol> ("ordered list") se usa cuando el orden de los elementos importa: un top 5, una clasificación, o pasos que deben seguirse en secuencia. El navegador numera automáticamente cada elemento (1, 2, 3...). Cada elemento de la lista se escribe con <li></li>.

<ol> <li>Bad Bunny</li> <li>Shakira</li> <li>Rauw Alejandro</li> </ol>
Lista desordenada — <ul>

<ul></ul> ("unordered list") se usa cuando el orden NO importa: por ejemplo, una lista de géneros musicales o de ingredientes. El navegador muestra cada elemento con una viñeta (•) en vez de un número. También se construye con <li></li> por dentro.

<ul> <li>Reguetón</li> <li>Pop</li> <li>Salsa</li> </ul>
Lo importante de <li>

<li> SOLO funciona correctamente si está dentro de un <ol> o de un <ul>: por sí solo, fuera de una lista, no tiene sentido. Cada <li> debe abrirse y cerrarse correctamente, y una lista puede tener tantos <li> como elementos necesites.

Repaso: <nav> y <article>

Ya conoces estas dos etiquetas de laboratorios anteriores; hoy las vuelves a usar. <nav></nav> agrupa el menú de navegación del sitio (los enlaces principales), y <article></article> contiene un contenido independiente y completo por sí mismo, como una publicación o la ficha de un artista. En este laboratorio, un truco muy común para armar un menú de navegación es combinar <nav> con enlaces <a>, uno junto al otro:

<nav> <a href="#">Inicio</a> <a href="#">Artistas</a> <a href="#">Canciones</a> <a href="#">Contacto</a> </nav>

El atributo href="#" significa que, por ahora, el enlace no lleva a ninguna parte todavía; solo estamos armando el menú.
